## How to Run This Notebook ##
----------------------------------------------------------

This notebook contains code for Time-Series Forecasting – Stock Prices. To run the code:

1.  Ensure you have the `all_stocks_5yr.csv` dataset available. If not, download it from the provided Kaggle link below-
		( https://www.kaggle.com/code/avikumart/timeseries-stock-price-analysis-forecasting/input).
2.  Run each code cell sequentially from top to bottom.
3.  The notebook will perform data loading, preprocessing, feature engineering, scaling, model training (Arima, Prophet), and rolling window evaluation.
4.  The output of each cell will be displayed below it.

📈 Time Series Forecasting – Stock Prices

This project focuses on forecasting stock prices using time-series analysis techniques in Python. The goal is to analyze historical stock data, model trends and seasonality, and predict future prices.

🚀 Features

Data preprocessing and exploratory analysis

Time-series forecasting using ARIMA and Prophet

Rolling window evaluation for robust performance comparison

Model evaluation using RMSE and MAPE



📂 Project Structure

Time_Series_Forecasting_–_Stock_Prices.ipynb – Main notebook

requirements.txt – Project dependencies

Stock_Price_Forecasting_Report.docx – Project report


📌 Conclusion

Prophet demonstrated better stability and interpretability compared to ARIMA for this dataset, making it suitable for deployment in real-world forecasting scenarios.
